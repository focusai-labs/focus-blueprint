# שלב 09: סריקת מלאי

בכל מקום שכתוב `bp`, מריצים `node "${CLAUDE_PLUGIN_ROOT}/scripts/bp.mjs"`.

## למה השלב הזה קיים

לפני שנוגעים בנתונים, צריך לדעת בדיוק מה צריך להיות מאחורי כל מסך. סוכן שבונה בלי רשימה כזאת בונה מה שנראה לו, והבעלים מגלה את זה מאוחר. כשהסטודנט מאשר את הרשימה, Claude יכול לבנות לבד, כי הוא יודע בדיוק מה מותר לו.

## מה קוראים לפני שמתחילים

- בקובץ המצב `.blueprint/state.json`, השלב הנוכחי הוא 9.
- המפה `.blueprint/map.json`, המסמכים `spec/prd.md` ו-`spec/decisions.md`, והמסכים בתיקייה `mockup`.
- הצמתים בתיקייה `${CLAUDE_PLUGIN_ROOT}/data/junctions` שבשדה `opens_at` שלהם יש 9.

## מה עושים

1. מריצים `bp stage start 9`.
2. קוראים עם הכלי Read את `${CLAUDE_PLUGIN_ROOT}/scripts/inventory.browser.js`. לכל מסך במפה: `browser_navigate` לקובץ, ואז `browser_evaluate` עם הטקסט של הסקריפט. שומרים את התוצאה.
3. מאחדים את התוצאות לקובץ `spec/inventory.md`: לכל מסך, כל פעולה, טופס, פריט מידע ושירות חיצוני, וליד כל אחד מה צריך מאחוריו: טבלה, הרשאה, אוטומציה או שירות חיצוני.
4. מקבצים את הרשימה ליכולות. כל יכולת היא דבר אחד שמשתמש עושה מקצה לקצה, כמו "לקוח מעלה קבלה". רושמים כל אחת: `bp map add capability '{"id":"<id>","name":"<שם>","screens":["…"],"data":["…"],"permissions":["…"],"automations":["…"],"status":"mock"}'`.
5. לכל שירות חיצוני שעוד לא הוחלט עליו, פותחים את הצומת שלו ומציגים את הכרטיסים, כמו בשלב 4. הבחירה נרשמת ב-`bp log add`.
6. מראים לסטודנט את הרשימה ואת היכולות, במילים פשוטות, ומבקשים אישור מפורש. אומרים לו שמהאישור הזה Claude עובד לבד בשלבי הבנייה, ועוצר רק בארבעה מקרים.

## מה לא עוצרים לשאול עליו

מהשלב הזה, הרשימה שהסטודנט אישר היא המנדט לעבוד לבד. לא שואלים אם להמשיך. מכריעים, וכל הכרעה נרשמת: `bp ruling add decision="…" why="…" price="…"`. עוצרים ושואלים רק בארבעה מקרים: לפני פעולה שמוחקת נתונים, לפני שינוי בהרשאות או במפתחות, לפני פעולה שעולה כסף או עולה לאוויר, וכשכל דרך בתוכנית היא ניחוש.

## מה חייב להיות נכון בסוף (ההוכחה)

- מספר המסכים שנסרקו שווה למספר המסכים במפה.
- לכל יכולת במפה יש לפחות מסך אחד.
- לכל שירות חיצוני יש החלטה ביומן השינויים.
- הסטודנט אישר את הרשימה, והאישור מצוטט בסגירה.

## מה נשאר בתיקייה

- הקובץ `spec/inventory.md`
- היכולות במפה `.blueprint/map.json`
