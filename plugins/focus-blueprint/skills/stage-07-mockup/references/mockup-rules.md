# הכללים לבניית מסך ב-mockup

כל מסך ב-mockup הוא קובץ HTML פשוט בתיקייה `mockup`. הכללים כאן הם החוזה שסקירת ה-UX בודקת.

- התגית הראשית היא `<html lang="he" dir="rtl">`, ובדף יש `<main>` אחד.
- בכל תצוגה יש פעולה ראשית אחת, מסומנת `data-primary`.
- כל פעולה הרסנית, כמו מחיקה, הסרה או ניקוי, מקבלת `data-confirm` עם מה שיאבד, ופותחת `<dialog>` שאומר את זה במפורש. בתוך החלון, הבחירה הבטוחה היא זו שמסומנת `data-primary`.
- כל מסך חוץ מדף הבית מציג קישור גלוי `<a data-anchor href="index.html">`.
- לכל שדה יש `<label for>`. שדה שאפשר להפוך לבחירה הוא `select`, או שדה מהסוג `date`, `tel`, `email` או `number`.
- שדה חובה מקבל `required`, ולידו `<small class="error" id="<שדה>-error">` שהשדה מפנה אליו עם `aria-describedby`.
- כפתור השליחה סגור עד שכל שדות החובה מלאים, בעזרת סקריפט קצר בדף.
- פעולה שלוקחת זמן מקבלת מצב `data-loading` שהסקריפט מדליק ומכבה.
- רשימה ארוכה מראה פריט חתוך בקצה, כרמז שיש עוד.
- טיוטה של טופס נשמרת ב-`localStorage`, וחוזרת כשהדף נטען שוב.
- אנימציה מכבדת את `prefers-reduced-motion`, ואין לולאה אינסופית חוץ מסימן טעינה.
- כל דף מצהיר על עצמו: `<meta name="blueprint:screen" content="<מזהה המסך>">` ו-`<meta name="blueprint:persona" content="<מזהה הפרסונה>">`.
